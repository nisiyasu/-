# Life Command Center スマホ版 v1 Visual Map

## Purpose
承認済みRIOT NEON画像を、可変UIを壊さず実装するための視覚マップ。

## HOME
基準画像: Home visual master / 864 x 1536。

### 固定視覚領域
- LIFE COMMAND CENTER / RIOT NEON ヘッダー
- 「今日これだけで勝ち」ヒーロー
- ライブ会場、人物、観客、ペイント、グランジ
- 7コマンドの視覚ボタン
- 7コマンド大枠の外側マゼンタ + 内側ライムイエロー
- XP / 累積前進 / 復帰成功 / 連続 / TODAY CLEARED 等の承認済みビジュアル

### 動的操作領域
承認済み画像上へ透明な44px以上のタップ領域を重ねる。
- 瞑想
- イメージング
- アファメーション
- リーディング
- ジャーナリング
- エクササイズ
- BTC1チャット

未定義の遷移先は作らない。

## SAVED LIST
基準画像: Save-list visual master / 864 x 1536。

### 固定視覚領域
- LIFE COMMAND CENTER / RIOT NEON ヘッダー
- 保存リスト大見出し
- 人物・ライブ会場・ネオン・ペイント・グランジ
- 上部の色・明るさ・質感

公開ランタイムでは承認画像の上部ヒーローを画像アセットとして使用し、それより下は可変UIをHTML/CSS/JSで再構成する。

### 可変領域
- 検索入力
- 絞り込み導線
- カテゴリ ALL / 日記 / ルール / 気付き / その他
- カード / 一覧
- 整理タイトル / 俺の原文
- 並び替え
- 最終同期 / 更新
- 結果件数
- 保存項目タイトル / 原文 / 日付
- 詳細表示

### 色役割
- Background: #020205 近傍
- Magenta: 選択、主要枠、保存リスト主アクセント
- Lime: 発進、ALL、重要アクセント
- Cyan: 情報、気付き、補助アクセント
- White: 主本文
- Amber: BTC等の補助アクセント

## Bottom navigation
v1の実ページは2つのみ。
- ホーム
- 保存リスト

承認画像に描かれた旧4ナビは、Home側では画像をクロップして実UIと二重表示させない。

## Rendering principle
`CSSに絵を描かせない。CSSには絵を配置させる。`
大規模な視覚表現は画像アセット、可変情報と操作はHTML/CSS/JSが担当する。
