# 4. ホーム 実装仕様

ホームの目的は次の2点。

1. 火を絶やさない
2. 目標を忘れない

ホームは「情報一覧」ではなく、
**目標を思い出す → 自分を整える → 本線を進める**
ための発進画面とする。

## 必須7コマンド

1. 瞑想
2. イメージング
3. アファメーション
4. リーディング
5. ジャーナリング
6. エクササイズ
7. BTC1チャット

### デザイン
- RIOT NEONを崩さない
- 黒背景
- マゼンタ / ピンク
- ライムイエロー
- シアン / ブルー
- 白
- 多色構成を維持
- 単色テーマ化しない
- 7個の個別ボタンは黒い内部 + 個別ネオンを維持
- 7個全体を囲む大枠を配置
- 大枠外側はピンク / マゼンタ系
- その内側に太めの黄色ライン
- 黄色ラインは機械的なベタ線ではなく、手描き・グランジ感
- 大枠は長方形ベース
- 後付けUIに見えない一体感を必須とする

### ボタン挙動
既存PC版またはリポジトリ内に明確な遷移先・挙動が存在する場合のみ、それを継承してよい。
仕様・既存実装にない遷移先を推測で作らない。
未定義の場合は `UNDECIDED` としてオーナー判断を要求する。

# 5. 保存リスト 実装仕様

目的:
**保存してきた大事なものを、スマホからすぐ見つけて読めるようにする。**

保存リストは、
- AIが整理した知識庫
- 過去の自分の脳へ直接アクセスする記憶庫

の両方として機能させる。

## 必須機能

### 検索
検索対象:
- 整理タイトル
- オーナー原文
- 本文

表示モードに関係なく全対象を検索する。

### カテゴリ
- ALL
- 日記
- ルール
- 気付き
- その他

### 表示方法
- カード表示
- 一覧表示

選択状態は保存する。

### タイトルモード
1ボタンで切替:
- 整理タイトル
- 俺の原文

#### 整理タイトル
AI整理済みの短いタイトルを表示する。

#### 俺の原文
オーナー本人の実際の発言・指示原文を表示する。
一覧では3〜4行程度まで表示し、詳細で全文を読む。

#### 原文保護
- 原文を修正しない
- 誤字・音声入力由来表現も保持
- 整理版とは別フィールド
- AI整理版で原文を上書きしない

### 並び替え
「新しい順」は実装候補として確定的。
その他のソートキーは仕様書で未決定なので勝手に追加確定しない。
完全実装に追加キーが必要なら `OWNER_DECISION_REQUIRED` として提示する。

### 詳細表示
- 項目をタップして本文を読む
- v1は「探す・開く・読む」が中心
- 大規模編集は実装しない

### 状態記憶
最低限:
- カード / 一覧
- 整理タイトル / 俺の原文

### 同期表示
候補:
- 最終同期時刻
- 手動更新
- 失敗時再試行

仕様または実データ接続方式が未確定なら、勝手にAPIを作らない。

### 大量データ
- 一覧時に全文を一括ロードしない
- 必要な詳細だけ後から読む方式を優先
- 件数が増えても検索・絞り込み・ソート・詳細表示が破綻しない
